# Port Status Checker

Learn common TCP ports and interpret service-reference information.

## Run
Open index.html in a modern browser. For File Protection Utility and Cryptographic Encryption Vault, run through localhost (for example VS Code Live Server) to enable Web Crypto. This is a port/service reference, not a live port scanner.

## Technology
HTML, CSS and vanilla JavaScript.

## Safety
Educational demonstration only. Do not use as a production security control or enter sensitive real-world data.
